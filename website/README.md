# Pupdate website

The one-page marketing site for Pupdate. Everything lives in a single self-contained `index.html` (inline CSS and JS, no build step, no external images; fonts come from Google Fonts).

- **Run locally:** open `index.html` in a browser, or serve this folder with any static server.
- **Deploy:** on Vercel, set this folder (`website`) as the Root Directory with framework preset "Other" and no build command. On GitHub Pages, serve from `/website`.

The "Watch the demo" button points to the `#demo` placeholder until a video link is added.
